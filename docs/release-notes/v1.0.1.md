# TamaNaruto v1.0.1

Three fixes from the first players.

- **The display no longer goes dark during fights.** Right after a tap the automatic dimming could think the screen had been untouched for weeks and drop it to almost black for a moment, which happened on nearly every turn of a fight. Tapping never dims the screen now; it still dims by itself after 90 seconds without a touch.
- **Swiping between screens is easier.** A swipe that curves a little, is a bit slow, or starts near the edge of the round display now counts. A swipe that started near the edge used to page the current screen instead of moving to the next one. To page, drag your finger along the edge.
- **No more doubled ninja.** Ino, Choji, Konohamaru, Kankuro, the Kiri ninja, Oto-Kette and Orochimaru each showed up twice side by side in some poses. Those poses are cut cleanly now.

**What you need to do:** install the firmware and send the village packs to the SD card again (all four, the new pictures are in them). Your save stays: leave "Erase device" unticked.
